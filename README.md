- 원인 후보를 추론하는 Agent와 이메일·대시보드 알림을 연결한 프로토타입 구현
- **2026년 하반기 현장 실증 대상으로 선정**

### AI 면접·커리어 추천 플랫폼

**6인 팀 팀장 · Agent 및 백엔드 개발**  
[코드](https://github.com/ssungcoding/AIco)

- 면접관 Agent 3개가 서류·답변의 일치성, 논리성, 면접 태도를 나눠 평가하고 토론해 최종 결과 도출
- 표정 분석·음성인식 기능과 Node.js·MySQL 백엔드 연동
- 면접 평가에서 단기·중기·장기 커리어 로드맵 추천까지 이어지는 서비스 구현
